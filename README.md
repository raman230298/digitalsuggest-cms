# DigitalSuggest CMS Studio

Dedicated edge-native content management system for [DigitalSuggest](https://digitalsuggest.com) powered by [EmDash CMS](https://emdashcms.com) and Cloudflare D1.

- **Admin Studio Host**: `https://cms.digitalsuggest.com/_emdash/admin`
- **Database**: Cloudflare D1 (`digitalsuggest-emdash`)
- **Public Website**: [digitalsuggest.com](https://digitalsuggest.com)
